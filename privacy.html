プライバシーポリシー

最終更新日：2026年10月31日

cominatsu analytics（以下「本ツール」）は、YouTubeチャンネル「cominatsu」の運営者が自分のチャンネルを分析するためだけに使用する個人用ツールです。

取得する情報

本ツールは、Google OAuthで運営者本人が許可した範囲（youtube.readonly、yt-analytics.readonly）で、運営者自身のチャンネルの動画情報・統計情報を読み取り専用で取得します。

利用目的

取得した情報は、運営者自身のチャンネル分析と、運営者のLINEグループへの通知にのみ使用します。

第三者提供

取得した情報を販売・第三者提供することはありません。本ツールは運営者以外のユーザーのデータを取得しません。

Google API Services User Data Policy

本ツールによるGoogle APIから取得した情報の利用は、Limited Use要件を含むGoogle API Services User Data Policyに準拠します。

アクセスの取り消し

Googleアカウントの権限設定から、いつでも本ツールへのアクセスを取り消せます。

Privacy Policy (English)

cominatsu analytics is a personal tool used only by the owner of the YouTube channel "cominatsu". It reads the owner's own channel data via the read-only scopes youtube.readonly and yt-analytics.readonly, uses it solely to analyze the channel and notify the owner's own LINE group, and never sells or shares it with third parties. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time from Google Account permissions.
